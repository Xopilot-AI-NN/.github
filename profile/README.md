## 👋 Добро пожаловать

**Xopilot** — независимая организация из Беларуси, основанная **Denis (DenBroLiik)** **1 февраля 2024 года**.

Мы занимаемся исследованиями и разработкой технологий искусственного интеллекта, создавая современные языковые модели, программное обеспечение и инструменты для локального запуска ИИ.

Наша цель — сделать современные технологии искусственного интеллекта доступными каждому: от разработчиков и студентов до компаний и исследовательских команд.

---

## 🚀 Наши проекты

### 🤖 Zephyr

**Zephyr** — семейство языковых моделей нового поколения.

В линейку входят:

- **Zephyr Micro** — компактные модели для Raspberry Pi, мини-ПК и слабых устройств.
- **Zephyr Elite** — универсальные модели для домашних компьютеров и рабочих станций.
- **Zephyr Ultra** — высокопроизводительные модели для серверов и профессиональных задач.

В будущем экосистема Zephyr будет включать:

- собственный Runtime;
- SDK для разработчиков;
- API;
- Agent Framework;
- инструменты обучения и оптимизации моделей.
